How it works

  • Sample. 1,922 public, non-fork, non-archived repositories with the most stars per language (GitHub Search API, collected once and extended over time). 0 are currently unreachable (moved or removed) and excluded.
  • Check. Once a day a HEAD request per path against the default branch: a 200 means the file exists, Content-Length is its size. .cursor/rules/ is checked as a directory. Names are matched case-sensitively, exactly as the conventions spell them.
  • Paths checked. Only these fixed locations on the default branch: AGENTS.md, CLAUDE.md, GEMINI.md, llms.txt, .cursorrules and .windsurfrules at the repository root, plus .github/copilot-instructions.md and .cursor/rules/ (AGENTS.md, CLAUDE.md, .cursorrules, .cursor/rules/, copilot-instructions.md, llms.txt, GEMINI.md, .windsurfrules). Nested files, for example in subdirectories or packages, are not checked.
  • Added today. A path present in today's scan and absent in the previous snapshot of the same repository. Links go to the file on GitHub via /go/<id>/, a plain redirect page.
  • Languages. Each language in the table above has a full list of its sampled repositories (every sampled repository is listed) at /lang/<slug>/, for example /lang/python/.
  • Baseline. A repository seen for the first time is baseline: files it already has are counted, but not shown as added.
  • Not done. No file contents are stored or shown. No accounts, no cookies, no JavaScript, no tracking of visitors.
