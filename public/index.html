How it works

  • Sample. 1,922 public, non-fork, non-archived repositories with the most stars per language (GitHub Search API, collected once and extended over time). 3 are currently unreachable (moved or removed) and excluded.
  • Check. Once a day a HEAD request per path against the default branch: a 200 means the file exists, Content-Length is its size. .cursor/rules/, .github/instructions/ and .claude/rules/ are checked as directories (presence only). A path's first scan is a baseline; days before it show "not tracked". Names are matched case-sensitively, exactly as the conventions spell them.
  • Paths checked. Only these 12 fixed locations on the default branch: AGENTS.md, CLAUDE.md, .cursorrules, .cursor/rules/, .github/copilot-instructions.md, llms.txt, GEMINI.md, .windsurfrules, AI_POLICY.md, .github/AI_POLICY.md, .github/instructions/, .claude/rules/. Nested files, for example in subdirectories or packages, are not checked.
  • Requests per repository. 12 path HEAD requests, plus 1 existence HEAD (only when every path is absent) and 1 moved-detection HEAD: 14 requests at most (one thread, with an optional GitHub token (used only for the one repository-exists API call)). AI_POLICY.md and .github/AI_POLICY.md: presence and size only, contents are never read. They count as 0 on days before their first scan; a path's first scan is a baseline, not an added entry.
  • Added today. A path present in today's scan and absent in the previous snapshot of the same repository. Links go to the file on GitHub via /go/<id>/, a plain redirect page.
  • Languages. Each language in the table above has a full list of its sampled repositories (every sampled repository is listed) at /lang/<slug>/, for example /lang/python/.
  • Baseline. A repository seen for the first time is baseline: files it already has are counted, but not shown as added.
  • Not done. No file contents are stored or shown. No accounts, no cookies, no JavaScript, no tracking of visitors.
