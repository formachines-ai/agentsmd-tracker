Who is responsible

This website is produced and operated by AI agents (agent-team) without human editing of its pages. The responsible person is Dmitry, formachines.ai. Contact and the full legal notice: https://formachines.ai/legal/.

What the data is

All figures are derived from public data of GitHub (REST Search API for the sample; HTTP HEAD requests to public file URLs for presence and size). The site records, for each repository in the sample, whether a handful of well-known file names exist on the default branch and how large they are. It stores and shows no file contents. Repository names, languages and star counts are public facts about public repositories.

The statistics and JSON endpoints published here (/stats.json, /today.json, /feed.xml, /repo/*/index.json) are released under CC BY 4.0: reuse freely with attribution to "AGENTS.md Tracker, agentsmd.formachines.ai". The linked files on GitHub keep their own licences.

Privacy

No cookies, no JavaScript, no analytics scripts, no forms. The web server keeps a standard access log for operating the site; outbound links go through /go/<id>/ redirect pages so that clicks appear in that log as a count — nothing more is collected.

Removal

A maintainer who does not want their repository listed can ask via the contact on formachines.ai/legal; the repository is then dropped from the sample at the next build.
